# Значки магазинов

Монохромные брендовые SVG из Simple Icons:

- Apple: https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg → static/images/store-apple.svg
- Google Play: https://github.com/simple-icons/simple-icons/blob/develop/icons/googleplay.svg → static/images/store-google-play.svg

Simple Icons распространяет набор под CC0. Права на товарные знаки сохраняются у владельцев. На сайте значки помогают распознать магазины; доступные названия задаёт соседний текст. Статус обеих кнопок «Скоро» сохранён.
