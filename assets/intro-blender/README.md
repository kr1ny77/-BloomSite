# Авторское Blender-вступление Bloom

Источник: ../../../bloom-intro-v4/Bloom-Intro.blend, последняя доступная версия v4. Исходник открыт в чистом Blender5.2.2 LTS с --disable-autoexec; камера Bloom_Reference_Front, диапазон1–90,30fps, исходный кадр1920×1080. Исходник и его материалы сохранены без изменений.

Использованы PNG-кадры из ../../../bloom-intro-v4/frames/ и Bloom-Final.png. Полный сценарий: лист1–36, рукописное loom37–77, финал78–90. На сайт перенесён готовый авторский рендер. Дополнительный пересчёт сцены не выполнялся.

scripts/prepare-intro.sh кодирует оригинальные PNG напрямую в H.264, CRF17, yuv420p,30fps,90кадров,3с, без аудио, faststart. Кадр1320×800 с началом330,150 сохраняет весь диапазон движения, включая кончик и основание высокого листа. Финальный кадр и первый постер подготовлены тем же crop и сохранены WebP lossless. Промежуточные PNG остаются в этой папке, за пределами опубликованного static/.

Материалы сайта: static/media/bloom-intro.mp4 (204910байт), static/images/bloom-wordmark-first.webp и bloom-wordmark-final.webp. Полное декодирование MP4 через ffmpeg завершилось без ошибок. Автовоспроизведение muted/playsinline, один проход. При reduced motion video src не назначается; HTML предоставляет финальный кадр без JS. Результаты браузерной проверки: docs/VERIFICATION.md.


## Прозрачные кадры и фон (2 ноября)

Первый и финальный кадры дополнительно пересчитаны из той же сцены с film_transparent=True и RGBA, без изменения освещения и материалов. Blender5.2.2 LTS, Cycles16 samples, Metal GPU, два CPU-потока, исходный1920×1080. Сохранены alpha-originals/0001.png и0090.png. Прозрачность углов подтверждена прямым декодированием: RGBA(0,0,0,0). prepare-intro.sh воспроизводит этот шаг через render-intro-stills.py. Исходный .blend остаётся сохранённым без изменений.

У MP4 H.264 остаётся непрозрачная подложка. После кодирования её RGB=(3,16,11) вместо фонового(6,17,13). mix-blend-mode:lighten на video сливает тёмную подложку с изолированной фоновой поверхностью hero. Статичные WebP используют настоящую альфа-прозрачность и обычное наложение. Новые зависимости не добавлялись; используются существующие Blender/ffmpeg/cwebp.
