# Оригиналы из Bloom-Keynote-v6.key

Файлы извлечены из Data/ ZIP-контейнера Keynote без перекодирования. Размеры и пропорции сохранены. Папка хранит исходники для дальнейшей работы и остаётся вне static/ и dist/.

- image7-20.png: цельная эмблема RGBA, 1254 × 1254.
- image2-10.png: иллюстративная предметная сцена, 1672 × 941.
- image3-12.png: оригинальная композиция двух демонстрационных экранов, 1672 × 941.
- image-8.png: иконка приложения.
- image5-16.png: фирменный шоппер.
- Остальные image: материалы презентации; st-*: превью слайдов; PresetImageFill*: встроенные материалы Keynote.

Текст и заметки слайдов проверены через распаковку IWA. В презентации изображения предметной сцены обозначены как AI-generated; интерфейсные оценки и показатели обозначены как демонстрационные. Права на исходные брендовые материалы предоставляет владелец проекта.
