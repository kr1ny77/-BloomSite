# Bloom

Русскоязычный сайт-презентация будущего приложения о составе, пищевой ценности и источниках информации о продуктах.

## Реальная версия и запуск

Рабочий сайт: Go + `templates/index.html` + `static/`. React/Vinext в `app/`, `components/`, `hooks/`, `lib/` является отдельной неиспользуемой заготовкой.

```sh
go run .
```

Открыть http://localhost:8080. Для другого порта: `PORT=8095 go run .`. Go встраивает файлы при сборке, поэтому после изменения HTML/CSS/JS нужно перезапустить сервер.

```sh
go test ./...
go vet ./...
node --test tests/*.test.mjs
node --check static/js/app.js
node --check static/js/motion.js
node --check static/js/intro.js
node --check static/js/presentation.js
./node_modules/.bin/oxlint static/js/app.js static/js/motion.js static/js/intro.js static/js/presentation.js scripts/build.mjs
npm run build
```

Сборка сначала компилирует ленивый Three.js viewer из `scripts/product-viewer-source.js` через esbuild, затем создаёт `dist/index.html` и `dist/static/`. Это тот же документ, который обслуживает Go. Развёртывание не является частью локального редизайна; существующие настройки хостинга сохранены.

## Меню, тема и движение

Native dialog обеспечивает модальное меню с Escape и фокусом. Обычные ссылки и details работают без JS. Обе темы поддерживают системный выбор и ручное переключение на время посещения. GSAP загружается только для компьютера при разрешённом движении; телефон и reduced-motion не скачивают движок. Прокрутка нативная вне банки. Колесо над геометрией 3D-банки вращает её по прямому запросу пользователя; пустая область canvas и zoom-жесты сохраняют обычное поведение. Глава #app объединяет три состояния упаковки и интерфейса; #how сохранён на её вступлении. На высоком desktop сцена закрепляется, на телефоне используются лёгкие переключатели, без JS все три сцены идут последовательно. Меню снимает scroll lock до перехода и синхронизирует состояние закрепления.

## Подключение финальной анимации

Первый экран статичен. Старое видео и Blender-источники сохранены, но автоматически не запускаются. После получения одобренного ролика заменить `data-src` у `.wordmark-video`, согласовать композицию/формат и добавить `data-intro-ready` на `.hero-brand`. При reduced motion или отказе воспроизведения остаётся полный статичный знак с Pacifico. Тесты primary/fail-safe путей: `tests/intro.test.mjs`.

## Ссылки магазинов

Две кнопки имеют `data-store="app-store"` / `data-store="google-play"`, `aria-disabled="true"` и подпись «Скоро». Когда появятся проверенные ссылки, заменить конкретный button на a, сохранить класс/data-store, добавить href, удалить aria-disabled и обновить статус. Не подставлять ссылки на поиск или чужие приложения.

## Перед публикацией

Нужны подтверждённые ссылки магазинов, методика оценки, источники с применимостью к образцам, юридические сведения владельца, контакт и проверка прав на исходные материалы. После выбора домена задать абсолютные canonical/og:image. Демонстрационные данные не являются подтверждением качества продукта.

## Интерактивная упаковка

`static/js/product.js` управляет прямыми жестами, клавиатурой и авто; `scripts/product-viewer-source.js` собирается в runtime `static/js/product-viewer.js`. Колесо захватывается только над геометрией, desktop drag вращает по двум осям без ограничений. Hover/focus приостанавливают авто; стрелки/Home/End/Space доступны с клавиатуры. Touch сохраняет нативный вертикальный скролл. Видимые вспомогательные controls удалены по запросу пользователя.

GLB и renderer ленивые, вне первого экрана. RAF работает только при видимом движении; modal, смена сцены, скрытый документ и reduced motion останавливают авто. Без WebGL/JS остаётся статичный poster. Камера, распознавание и API не используются; `scanner.js` запускает один иллюстративный проход линии. Исходники 3D/этикетки в `assets/yogurt-model`, новые ImageGen-материалы и prompts в `assets/generated/product-polish.md`.

Последние решения, сравнение до/после, критерии и фактические проверки: [docs/PRODUCT-POLISH.md](docs/PRODUCT-POLISH.md). Новый lowercase wordmark применяется только в closing; оригинальный hero с Pacifico и шапка сохранены.
