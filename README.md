# Bloom — beta

Одна информационная страница о продукте Bloom: шесть сцен, оригинальная айдентика и изображения из Bloom-Keynote-v6.key, плавная прокрутка и последовательное объяснение демонстрационной оценки.

## Локальный запуск

Требуется Go 1.22 или новее. Из этой папки:

```sh
go run .
```

Откройте http://localhost:8080. Другой порт: `PORT=8090 go run .`.

Используются `net/http`, `html/template`, встроенная раздача статики через `embed.FS`, HTML, CSS и vanilla JavaScript. Библиотеки GSAP 3.13.0, ScrollTrigger 3.13.0 и Lenis 1.3.4 хранятся локально в static/js; сеть для работы страницы не нужна.

## Исходники

- `templates/index.html` — текст и структура шести секций.
- `static/css/style.css` — тема, адаптивность и оформление.
- `static/js/app.js` — анимации и переходы по разделам.
- `static/images/` — оптимизированные оригиналы из Keynote. Исходные изображения сохранены. Три экрана приложения теперь представлены согласованными статичными HTML-мокапами с одинаковыми рамками и пропорциями.
- `main.go` — HTTP-сервер.

Все кнопки магазинов — заглушки с aria-disabled. Сайт не вычисляет оценки, не сканирует продукты, не собирает данные. В примере рейтинга 92/100 и в мокапах используются исключительно демонстрационные данные. Реальные исследования, нормативы и протоколы не выдумываются.

На компьютере круг оценки закрепляется внутри собственного раздела через CSS sticky; текст и секции остаются в обычном потоке. Маски, исчезновение текста и GSAP pin для целых секций удалены. На телефоне история идёт последовательно без закрепления. При prefers-reduced-motion анимации отключены. Если библиотеки не загрузились или JavaScript отключён, содержание остаётся видимым.

## Sites

Официальный scaffold Sites сохранён вместе с зависимостями. Основной продукт использует Go и статичный HTML по брифу; React-компоненты scaffold не участвуют в работе страницы. Для размещения в Sites создаётся статичная копия той же страницы:

```sh
npm install
npm run build
```

Результат: `dist/index.html` и `dist/static/`. Sites размещает статический результат; Go-сервер предназначен для локального запуска. Изображения и JS входят в сборку, внешних ссылок на магазины, трекеров или API нет.

Обновление экранов: минимальные примеры результата, состава и источников, без рекламных заголовков внутри интерфейса. Общая подпись под мокапами отмечает демонстрационные данные. Корпуса включают тонкую металлическую рамку, Dynamic Island и индикатор жестов. При прокрутке добавлены движение знака, раскрытие фотографии, прорисовка линий, последовательное появление устройств и заполнение рейтингов; текст не скрывается. Все эффекты отключаются при prefers-reduced-motion.
